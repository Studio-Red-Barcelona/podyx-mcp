# Podyx cursor plugin

Build the distributable from the repository with `npm ci && npm run package:plugins`. Use the complete `dist/podyx-cursor` folder or ZIP, not this template alone. The archive includes the runtime and dependencies; Node.js 22+ must be installed and available to the desktop app.

Configure the studio key in the plugin configuration dialog. Writes are off by default.

See the repository docs/clients.md for client-specific setup, transport limitations and verification.
