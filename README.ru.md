# Podyx MCP

Неофициальный MCP-сервер для владельцев студий в Podyx. Позволяет работать с расписанием, бронированиями, клиентами, пакетами и отчётами через AI-помощника.

**150 инструментов. По умолчанию включены 65 инструментов чтения и предварительного расчёта; изменения включаются отдельно.**

## Podyx и документация API

- [Сайт Podyx](https://www.podyx.com/)
- [Интерактивный справочник API v2](https://docs.podyx.com/api/docs?version=2)
- [Спецификация OpenAPI v2 (JSON)](https://docs.podyx.com/api/openapi-v2.json)
- [Спецификация API v1 (JSON)](https://docs.podyx.com/api/openapi.json) — используется для отчётов и чтения данных через прежнюю версию API.

## Подключение

Нужны Node.js 22+ и свой API-ключ из **Podyx → Settings → API keys**. Ключ хранится на вашем компьютере, например в `~/.config/podyx-mcp/.env`:

```dotenv
PODYX_API_KEY=YOUR_PODYX_API_KEY
PODYX_ENABLE_WRITES=false
```

Скачайте подходящий плагин из [GitHub Releases](https://github.com/Studio-Red-Barcelona/podyx-mcp/releases), когда появится первый релиз. Для работы из исходников:

```sh
git clone https://github.com/Studio-Red-Barcelona/podyx-mcp.git
cd podyx-mcp
npm ci --ignore-scripts
npm run configs
```

Готовые настройки появятся в `generated/`. Их нужно добавить в конфигурацию нужного клиента. Секретный ключ в эти файлы не записывается.

## Клиенты

Docker — дополнительный способ запуска без Node.js и клонирования исходников. Образы для amd64/arm64 публикуются в GHCR вместе с релизом; ключ передаётся при запуске, журнал хранится в volume. Есть stdio и пример HTTP-развёртывания через Compose. [Инструкция по Docker и обновлению](docs/docker.md). Первый образ появится после релиза с этой поддержкой.

- Cursor, Codex и Claude Code: локальный MCP и пакеты плагинов.
- Claude Desktop: готовая конфигурация локального сервера.
- ChatGPT: локальный сервер через Secure MCP Tunnel либо поддерживаемый desktop-плагин.
- Grok: локальный адаптер через платный xAI API или удалённое подключение через HTTPS.

Локально работают MCP и доступ к ключу; выбранные результаты инструментов передаются AI-провайдеру. Подробности и ограничения: [подключение клиентов](docs/clients.md).

## Примеры

- «Найди свободные два часа в субботу для этого сетапа».
- «Сравни загрузку и выручку с предыдущим месяцем».
- «Покажи остаток пакета клиента».
- «Объясни надбавку в расчёте цены».
- При включённых изменениях: «Предварительно посчитай продление съёмки на час».
